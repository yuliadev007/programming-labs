Краткие теоретические сведения

Git - это распределенная система контроля версий, предназначенная для

фиксации изменений в файлах, безопасного ведения параллельной разработки

и возможности возврата к предыдущим версиям исходного кода.

Основные понятия контроля версий:

Локальный репозиторий - скрытая директория .git, развертываемая на

локальном компьютере пользователя, где изолированно сохраняется вся

история модификаций файлов проекта.

Удаленный репозиторий - точная копия структуры проекта,

размещенная на внешнем сервере в сети (в данном практикуме – на веб-

сервисе GitHub), выполняющая функции облачного резервного копирования,

демонстрации и совместной интеграции кода.

Коммит (Commit) - атомарно зафиксированное состояние файлов

проекта, снабженное уникальным идентификатором и обязательным

осмысленным текстовым описанием внесенных изменений.

оформлению последующей документации в формате Markdown.
