# **Краткая теория:** 

- Условный оператор if: Используется для проверки логических условий и ветвления алгоритма. Код внутри блока выполняется только тогда, когда условие истинно (True). В Python обязательным правилом является использование двоеточия (:) и отступов в 4 пробела. 

 Цикл for..in и функция enumerate(): Цикл for осуществляет последовательный перебор элементов списков или диапазонов. Встроенная функция enumerate() нумерует элементы последовательности, автоматически возвращая на каждой итерации пару: индекс (счетчик) и само значение элемента. 

- Пользовательские функции (def): Многократно используемые блоки кода, которые объявляются ключевым словом def, принимают входные параметры и возвращают результат в вызывающую программу с помощью оператора return. Строки документации (docstrings) размещаются в тройных кавычках сразу после заголовка функции. 

# **Индивидуальное задание (Вариант 7)** 

Разработать функцию monitor_transformer_tok(i_list, i_max), опрашивающую замеры тока в цикле. Если текущий ток $I > I_{max}$, вывести аварийный сигнал, прервать цикл и вернуть время срабатывания защиты (индекс замера) и значение аварийного тока. 

# **Исходный код программы** 

def monitor_transformer_tok(i_list, i_max): 

for time, i in enumerate(i_list): 

if i > i_max: print(f"-> Аварийный сигнал! Ток: {i:.2f} А") 

return time, i 

max_i = float(input("Введите максимальный ток (например, 20.0): ").replace(',', '.')) 

user_input = input("Введите замеры тока через пробел (например, 10.0 11.0 12.0 31.0): ") 

tok = [float(x.replace(',', '.')) for x in user_input.split()] 

resultat = monitor_transformer_tok(tok, max_i) 

print("Результат работы (время, аварийный ток):", resultat)
