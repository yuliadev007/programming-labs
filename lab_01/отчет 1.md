# **Краткая теория:** 

- Интерпретируемость языка: Язык Python является интерпретируемым. Исходный код при первом запуске транслируется в промежуточный байт-код и выполняется виртуальной машиной (CPython). 

- Динамическая типизация: Переменные в Python представляют собой ссылки (имена), которые связываются с объектами в динамической памяти прямо в момент присваивания значения. Тип переменной определяется автоматически. 

- Форматирование f-строк: Форматированные строковые литералы (fстроки) позволяют удобно внедрять выражения и переменные внутрь текстовых строк. Конструкция вида {P:.4f} специфицирует вывод вещественного числа с фиксированной точностью ровно до четырех знаков после запятой. 

- Математический модуль math: Встроенная библиотека Python, предоставляющая доступ к базовым математическим функциям, включая извлечение квадратного корня с помощью функции math.sqrt(). 

# **Задание (Вариант 7)** 

Физическая величина / Формула: Мощность трехфазной сети: P = sqrt(3) * U * I *cos(f) 

Требование: Осуществить динамический ввод параметров, выполнить расчет и вывести результат строго с помощью f-строк с округлением вещественной части до 4 знаков после запятой. 

# **Код программы** 

import math  # Подключаем математику для корня 

print("Расчет мощности трехфазной сети") 

U = float(input("Введите напряжение U (например, 380.0): ")) 

I = float(input("Введите ток I (например, 15.5): ")) 

cos_f = float(input("Введите коэффициент мощности cos(f) (например, 0.85): ")) 

P = math.sqrt(3) * U * I * cos_f 

print(f"Результат: Мощность P = {P:.4f}") 

**Вывод** : В ходе лабораторной работы были успешно освоены базовые компоненты синтаксиса языка Python в среде VS Code. На примере программы расчета мощности трехфазной сети отработаны механизмы динамического связывания типов данных при преобразовании пользовательского ввода через функцию float(input()). Подключение стандартного модуля math позволило использовать точную функцию квадратного корня math.sqrt(3). Вывод итогового значения мощности выполнен с помощью инструмента форматирования строковых литералов (f-строк) с фиксацией округления дробной части до 4 знаков после запятой ({P:.4f}), что исключает появление избыточной погрешности округления при отображении результата..
