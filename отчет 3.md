Краткая теория 

Модульная организация программ: Модуль в Python представляет собой отдельный файл с расширением .py, содержащий определения функций и переменных. Архитектура обеспечивает повторное использование кода и декомпозицию сложных программных complexes. Для импорта конкретных функций используется инструкция from module import function. 

Точка входа __name__: Чтобы отделить код тестирования внутри модуля от основного вызываемого функционала, применяется проверка специальной встроенной переменной if __name__ == '__main__':. 

Системный модуль sys: Предоставляет доступ к параметрам среды исполнения. Список строк sys.argv содержит аргументы командной строки, переданные скрипту при его непосредственном запуске из консоли. Базовые структуры данных и срезы: Списки (list) — упорядоченные изменяемые динамические массивы. 

Множества (set) - неупорядоченные коллекции уникальных элементов, автоматически исключающие дубликаты. Синтаксис среза имеет вид [start:stop:step], где отрицательный шаг -1 выполняет быстрый разворот последовательности в обратном порядке. 

<mark>Задание Вариант 7 Анализ логов контроллеров АСУ ТП</mark> Физический процесс / инженерное явление: 

В процессе работы промышленного сервера АСУ ТП формируется текстовый файл журнала событий. Инженеру по автоматизации требуется оперативно фильтровать аварийные сообщения, извлекать уникальные коды ошибок и просматривать последние записи в обратном хронологическом порядке. 

<mark>Задачи модуля (variant_mod.py):</mark> 

1) extract_errors(log_lines) — фильтрует список текстовых строк, оставляя только записи со статусом 'ERROR'; 

2) get_error_codes(log_lines) — извлекает множество (set) уникальных кодов ошибок из логов; 

- 3) get_recent_logs(log_lines, count=5) — с помощью среза [-count:] и разворота [::-1] возвращает 

свежие записи в обратном порядке. 

Требования к программе main.py: 

• Считать число запрашиваемых записей count из sys.argv[1] (дефолт 3).
